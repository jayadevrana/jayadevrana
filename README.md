## Building now: [SuperCharting](https://supercharting.com)

A browser charting workstation that runs Pine Script: charts, strategy tester, optimiser, screener and alerts.

- **[Free Pine Script Checker](https://supercharting.com/pine-script-checker)**: paste a Pine v6 script; it compiles it, runs it on sample candles and names the line of the first error. No sign-up.
- **[Free Pine Script indicators](https://jayadevrana.in/free-pine-script-indicators/)**: open-source TradingView indicators and strategies with chart snapshots and honest backtests (costs included).
